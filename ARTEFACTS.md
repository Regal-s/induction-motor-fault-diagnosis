# Project artefacts — full index

Everything materially produced by this project is either committed to the
GitHub repository (`Regal-s/induction-motor-fault-diagnosis`, branch
`master`) or, where the file is too large for version control, kept locally
in `D:\Naveen\` with a documented regeneration recipe.

This file is the single index. Use it to:
* know what was produced and where it lives;
* clone the repo onto a fresh machine and recover every artefact that fits
  in version control;
* regenerate the non-versioned binaries from the saved configs / scripts.

The headline corpus statistics are in `report.md` and `manuscript/main.tex`
Section IV; this file is just the file-system map.

## 2. Pretrained / saved model artefacts (committed)

### 2.1 Deployed XGBoost cascade
`realtime/deploy/` — production model bundle used by the Jetson Nano deployment
(\S IV-K of the manuscript):
* `detect.json` — Stage-1 detection booster (XGBoost native JSON, $\approx\!\!220$ KB)
* `severity.json` — Stage-2 ordinal severity booster ($\approx\!\!2.5$ MB)
* `phase.json` — Stage-3 phase booster ($\approx\!\!1.7$ MB)
* `meta.json` — `(fs, f0)`, feature names, ordinal levels, phase labels, Stage-0 onset config

Load:
```python
from xgboost import XGBClassifier
m = XGBClassifier(); m.load_model('realtime/deploy/detect.json')
```

### 2.2 Benchmark model bundles
`trained_models/<Model>/<task>.{joblib | json | npz}` for each of the FAST
benchmark models trained on the full simulation corpus (generated by
`save_all_models.py`):

| Model | Format | Loader |
|---|---|---|
| LogReg, SVM-RBF, KNN, MLP, RandomForest | `joblib` | `joblib.load(path)` |
| XGBoost | XGBoost JSON | `XGBClassifier.load_model` |
| NG-RC | ridge head `joblib` | `joblib.load` + `reservoir_models._ngrc_features` |
| ESN | reservoir weights `npz` + ridge head `joblib` | `reservoir_models.ESNFeaturizer` + `joblib.load` |

Each model file is paired with a `<task>.meta.json` recording the feature
columns, hyperparameters, training time, and load instructions.

### 2.3 Slow / deep / foundation models — reproducibility configs
`trained_models/__configs__/slow_models_reproducibility.json` —
hyperparameters for xLSTM, ROCKET, PatchTST, iTransformer, TimesNet, Mamba,
TTM, Chronos-Bolt, and TabPFN-2.5. These models are reproducible by re-running
`benchmark_models.py` against the captured configs; the trained weights are
not persisted (too large or training time prohibitive on this corpus).

## 9. How to reproduce everything on a fresh system

```bash
git clone https://github.com/Regal-s/induction-motor-fault-diagnosis.git Naveen
cd Naveen
pip install numpy pandas scikit-learn xgboost scipy pyarrow shap antropy EntropyHub
pip install torch transformers chronos-forecasting granite-tsfm   # optional, for the modern/foundation models

# (1) If you have the PSCAD source:
python data_index.py    # -> manifest.csv
python segment.py        # -> dataset/windows.npy
python features.py       # -> dataset/features.parquet

# Otherwise: the features.parquet is already committed, so you can skip 1.

# (2) Reproduce the deployed cascade:
python train_stage1.py && python train_stage2.py && python train_stage3.py
python cascade.py

# (3) Reproduce the 14-model benchmark (~12 hours on a desktop CPU):
python benchmark_models.py
python benchmark_report.py

# (4) Reproduce the trained-model bundles in trained_models/:
python save_all_models.py

# (5) Compile the manuscript:
cd manuscript && tectonic main.tex
```
